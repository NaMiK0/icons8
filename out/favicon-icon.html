Favicon Icon

A favicon icon appears in the browser tab next to your page title, helping visitors identify your site quickly. Select a design that matches your brand and download the file in the required format for your website.

Choose the Right Size and Format

Web browsers expect a specific file named favicon.ico, but modern sites often use PNG or SVG files for sharper display on high-resolution screens. Decide whether you need a single .ico file for broad compatibility or a set of images in different pixel dimensions for mobile devices and desktops.

Select a Style for Your Brand

Icons come in flat, line, or 3D styles, each creating a different visual impression in the browser tab. A simple line icon may suit a minimalist site, while a colorful flat icon can make a brand stand out in a list of open tabs. Pick a style that aligns with the rest of your website's design.

Prepare the File for Upload

Once you have chosen an image, ensure the file is saved with the correct name and extension for your web server. Most browsers look for a file named favicon.ico in the root directory, though some setups require linking to the image in the HTML code. Check the license details shown with the asset to confirm how you can use it.

Frequently asked questions

How do I download a favicon?

Select the icon you want, choose the file format and size, and save the image to your computer before uploading it to your website.

What is a favicon.ico file?

It is a standard image file format used by web browsers to display a small icon in the tab bar and bookmarks.

Can I get a free favicon?

Many icons are available for download, but you must check the specific license terms listed with each asset to see if attribution or a paid plan is required.

What size should a favicon be?

Common sizes include 16x16, 32x32, and 48x48 pixels, but providing multiple sizes ensures the icon looks clear on all devices.

Do I need a specific format for mobile?

Mobile browsers often prefer PNG or SVG formats for better scaling, so it is helpful to provide these alongside the standard .ico file.

Where do I put the favicon on my site?

Place the file in the root folder of your website and name it favicon.ico, or add a link to the image in your HTML head section.
